# The Postal Trace (phone version)

A Disco Elysium-style courier RPG that runs in the browser. Made for phones, works on desktop too.

**Play:** open the GitHub Pages link for this repository in your phone's browser.
On iPhone (Safari) tap Share → *Add to Home Screen*; on Android (Chrome) tap ⋮ → *Add to Home screen* / *Install app*. It then opens full screen like an app.

- Tap to walk, tap twice to run, pinch to zoom.
- Saves stay on your own phone, in the browser. Use *Save to file* in the menu if you want a copy, since some browsers clear site data.
